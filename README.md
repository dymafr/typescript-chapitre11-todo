# Todo TypeScript — chapitre 11

Projet Todo utilisé dans le chapitre 11 du cours TypeScript Dyma.

## Prérequis

- Node.js 20.19 ou une version 22.12 et ultérieure
- npm

## Commandes

```bash
npm ci
npm run dev
npm run typecheck
npm run build
npm run preview
```

Le build de production exécute le contrôle des types TypeScript avant de lancer
Vite.
